# 故事生成失败与质量下降复盘（2026-09-03 至 2026-09-05）

## 证据范围

此前服务只把生成日志写到终端，没有持久化，因此本报告依据仍可读取的终端输出、`custom_story_requests` 最终状态和故事检查点进行复盘，不能声称覆盖两天内每一条模型调用。自本次修改起，日志会写入 `custom_story_logs`，后续可直接按任务和时间查询。

## 观察到的现象

| 阶段 | 观察 | 结论 |
| --- | --- | --- |
| 早期候选 | 原始候选多次达到 353–415 词，并并发进入压缩 | 旧 Token 预算和提示没有形成有效长度压力 |
| 固定长度受控运行 | 可用候选出现 249、270、262、289 词 | 310 词上限本身可以产出合格长度 |
| 融合 | 融合稿曾从合格长度扩张到 367–390 词，压缩后四维均分降至 4.50 | 先融合再压缩会破坏因果和连续性 |
| 高分样本 | 第 3 集出现 276 词、四维均分 7.75 的候选 | 字数限制不是质量下降的充分原因 |
| 词汇修稿 | 该高分稿覆盖率从 83.7% 调整到 87.0%；后续整篇修稿缩至 255 词且覆盖率降为 85.5% | 语义合格后继续整篇改写是明确的质量下降来源 |
| 最近三轮质量重试 | 每轮最佳均分约为 6.50、6.50、6.75 | 失败经验和合同约束过多时，正文趋向任务清单，儿童吸引力持续偏低 |
| JSON 结构 | 模型把“四个句子数组”返回成顶层 20–27 个句子或异常对象 | 嵌套句槽输出合同不适合当前模型，造成无意义结构重试 |
| 上游容量 | 多次出现 MiniMax 529 / 2064 | 供应商过载与内容、JSON 质量无关，必须独立分类并停止 |
| 新版持久日志抽样 | 00:04–00:07 共 71 条日志，记录 38 次定长校正提示、18 份最终隔离稿，只有 2 份校正后进入评审 | 外层 3 次虽有上限，但“5 份首稿 × 每稿最多 2 次校正”仍放大了单次重试成本 |
| 后续集短稿 | 多份校正稿落在 188–217 词，并因 220 词硬下限失败 | 用户要求的初中 310 词上限被错误实现成了 220–310 双向硬区间；下限附近不应触发整稿重写 |

## 根因判断

字数限制调整与质量下降存在间接相关，但不是“310 词太短”这一单一原因：

1. 大量初稿先写到 350–500 词，再被压到 220–310 词，压缩过程容易删除动机、过渡和伏笔证据。
2. 已通过语义门禁的稿件仍因词汇覆盖率触发整篇修稿，错误地把“换几个难词”执行成了摘要或重写。
3. 最多 8 条、每条 320 字的历史失败意见会反复进入新提示，和季纲、四段合同、线索合同叠加后形成约束拥塞。
4. 严重句数和句长偏差此前被记录为“轻微偏差”并直接放行，导致分级语言和可读性评分下降。
5. 嵌套句槽 JSON 增加了模型结构错误，却没有稳定控制正文长度。
6. 429/529 在局部恢复回调中被包装成结构错误，使真实基础设施问题难以辨认。
7. 句子任务卡被当成过严的结构门禁；文章已经回到合理总长度后，仍可能只因每段多 3–5 个短句而再次重写。

## 已落地修复

- 每个可见队列尝试只包含一批候选和一次融合；每集质量重试仍有明确的三次上限。
- 首稿、融合和压缩统一使用发布词数门禁，退化稿不能覆盖高分原稿。
- 语义合格、只差词汇覆盖率时，只允许一次等长局部换词，长度最多波动 6 词或约 2.5%。
- 高分但未发布的正文保存为下一轮精英候选，不再因后续词汇门禁丢失。
- 历史失败提示缩为最多 6 条、每类 1 条、每条 160 字。
- 句数偏差超过 2 或单句超过预算 6 词以上时，按严重偏差处理，不再标为轻微。
- 输出恢复为简单的 `title + 4 个段落字符串`，句数由本地校验，不再要求嵌套句子数组。
- 局部恢复遇到 429/529 时原样上抛为模型服务繁忙，不进入 JSON 结构纠错。
- 新增 `custom_story_logs` 持久日志表，供后续按两天、任务或阶段做精确统计。
- 初中后续集仍以 220–310 词为目标，但发布范围放宽为 180–310；188–219 词的连贯稿交给四维质量评审决定，不再机械作废。
- 310 词文章的正文输出预算由 670 Token 收紧到 487 Token，先从生成端施加长度压力，减少“写长再压缩”。
- 句数任务卡保留为写作目标和评审依据，只有极端偏离或超长句才触发前置重写。
- 每次执行任务前以数据库状态做原子领取；失败任务或重复入队事件无法直接启动生成，自动重试也先回到明确的 `queued` 状态。
- 后续三次人工重试进一步定位到三类独立问题：空第五段的本地归一化返回错误、语义优化阶段 `ECONNRESET` 未恢复，以及 `mechanical_repaired` 检查点在词汇局部修复耗尽后原地自动重试。现已分别增加空段过滤返回、一次传输重试、`lexicalRepairExhausted` 状态和相同检查点错误指纹熔断。
- 初中词汇发布识别由仅 `zk` 调整为 `zk + gk`。同一篇 291 词、四维均分 7.75 的第 3 集正文，覆盖率由 83.5% 校准为 92.4%，超过 90% 发布底线；95% 仍只作为优化目标。
